# LP 46 — Bem-estar intestinal

Landing page estática (HTML + CSS + JS puro) para a linha **46 Geleia** e **Complexo Senna Almeida Prado 46**.

## Estrutura

```
index.html   # marcação da página
style.css    # estilos
main.js      # interações (carrossel de farmácias etc.)
assets/      # imagens exportadas do PSD
```

## Rodando localmente

Qualquer servidor estático serve. Com o PHP do XAMPP:

```bash
C:/xampp/php/php.exe -S localhost:8046
```

Depois abra http://localhost:8046.
